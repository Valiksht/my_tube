## Анализ завершён

Найдена **главная причина** ошибок:

### Проблема: Дублирование обработчиков JavaScript

На странице видео (`video.html`) есть **два набора** обработчиков для кнопок лайков и подписок:

1. **Inline-скрипт** внутри `video.html` (строки 314-390)
2. **Глобальный** `app.js` (функция `initFormHandlers()`)

При клике срабатывают оба → отправляются **два fetch-запроса** подряд:
- Первый succeeds → состояние переключается
- Второй либо fails (конфликт), либо переключает обратно → попадает в `.catch()` → ошибка «Не удалось обработать лайк»

### Комментарии

Форма комментариев отправляется через обычный HTML POST на JSON-API эндпоинт. Это некорректно — форма ожидает HTML-ответ, а API возвращает JSON. Нужно переделать на AJAX.

### План исправлений

1. **Удалить inline-скрипт** из `video.html` (оставить только глобальный `app.js`)
2. **Добавить переключение `.active` класса** в глобальные обработчики `app.js`
3. **Переделать комментарии на AJAX** с динамическим обновлением списка

План записан в файл. Готов приступить к реализации?
