## Внесённые изменения

**Проблема:** Когда через HTML-форму не загружается превью, но форма отправляется, браузер может отправить пустой файл с `content_type=None`. Проверка `thumbnail_file.content_type not in allowed_thumb_types` срабатывала, потому что `None not in [...]` = `True`.

**Решение:** В двух местах добавил проверку `thumbnail_file.filename` — превью обрабатывается только если файл существует И имеет имя:

1. **`app/api/pages/video_pages.py`** (строка 144) — HTML-форма загрузки
2. **`app/api/videos.py`** (строка 183) — REST API

Было:
```python
if thumbnail_file:
```

Стало:
```python
if thumbnail_file and thumbnail_file.filename:
```

Теперь превью полностью опционально. Вы можете загружать видео без превью — оно будет равно `null` в базе данных.
