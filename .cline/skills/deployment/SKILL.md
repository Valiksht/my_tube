# Навык развёртывания проекта

Проект должен запускаться на чистой Ubuntu
одной командой.

Основной инструмент — Docker Compose.

## Docker

Для приложения подготовь Dockerfile.

Не устанавливай все зависимости
без необходимости.

Используй отдельные сервисы для:
- FastAPI.
- PostgreSQL.
- MinIO.
- Background Worker.

Если для фоновой обработки нужна отдельная
очередь задач, сначала объясни выбор
технологии и необходимость её использования.

## Docker Compose

В docker-compose.yml должны быть описаны
все необходимые сервисы.

Продумай:
- Переменные окружения.
- Volumes.
- Networks.
- Healthchecks.
- Зависимости сервисов.
- Перезапуск контейнеров.

Не храни пароли непосредственно
в docker-compose.yml.

## Запуск

Развёртывание должно включать:

1. Подготовку окружения.
2. Запуск контейнеров.
3. Ожидание готовности PostgreSQL.
4. Применение миграций Alembic.
5. Подготовку MinIO и бакета.
6. Запуск приложения.
7. Запуск фонового worker.

Не считай запуск контейнера доказательством
готовности приложения.

## Ubuntu

Учитывай, что итоговая проверка будет
проходить на чистой Ubuntu.

Не используй Windows-специфичные команды
в Linux-скриптах.

Не требуй предварительной ручной установки
Python и PostgreSQL на сервере,
если эти компоненты запускаются в Docker.

## Проверка развёртывания

Проверь:
- Сборку образов.
- Запуск контейнеров.
- Подключение к PostgreSQL.
- Подключение к MinIO.
- Выполнение миграций.
- Работу FastAPI.
- Работу фонового worker.
- Загрузку и просмотр видео.

## Документация

Обновляй README.md.

Добавляй инструкции по запуску,
настройке переменных окружения и диагностике.

Не записывай настоящие пароли
и ключи в документацию.
