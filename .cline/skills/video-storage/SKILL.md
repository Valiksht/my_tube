# Навык работы с видео

Видеохранилище — основная часть моего проекта.

Я хочу реализовать загрузку, хранение,
обработку и воспроизведение видео.

## Общий принцип

Видео не должны храниться непосредственно
в PostgreSQL.

В PostgreSQL хранятся:
- Название.
- Описание.
- Автор.
- Продолжительность.
- Размер файла.
- Статус обработки.
- Тип доступа.
- Ключ объекта в хранилище.
- Ключ превью.

Сами файлы хранятся в MinIO или S3.

## Загрузка видео

При реализации загрузки:

1. Проверяй авторизацию пользователя.
2. Проверяй размер файла.
3. Проверяй формат и содержимое файла.
4. Не доверяй имени файла.
5. Создавай уникальный ключ объекта.
6. Загружай файл в хранилище.
7. Сохраняй метаданные в БД.
8. Передавай видео на дальнейшую обработку.

Не загружай большие файлы целиком в память.

Продумывай обработку ошибок и очистку
неполностью загруженных объектов.

## Обработка видео

Для обработки можно использовать FFmpeg.

Не запускай тяжёлую обработку непосредственно
в HTTP-запросе.

Используй фоновый worker.

После обработки обновляй статус видео.

Если обработка завершилась ошибкой,
сохраняй статус FAILED.

## Воспроизведение

Продумай поддержку HTTP Range Requests.

Плеер должен иметь возможность:
- Начать воспроизведение.
- Перематывать видео.
- Запрашивать отдельные диапазоны байтов.
- Продолжать воспроизведение после перемотки.

Правильно обрабатывай:
- Range.
- Content-Range.
- Accept-Ranges.
- Content-Length.
- HTTP 206 Partial Content.
- HTTP 416 Range Not Satisfiable.

Не отдавай весь большой файл
при каждом запросе плеера.

## Приватные видео

Перед выдачей файла обязательно проверяй права.

Нельзя полагаться только на frontend.

Нельзя использовать публичный доступ к объектам
для приватных видео.

Если используешь временные подписанные ссылки,
продумай срок их действия и момент проверки прав.

## Превью

Используй FFmpeg для создания изображения
из выбранного кадра видео.

Сохраняй превью в объектном хранилище.

В БД сохраняй ключ превью.

## Проверка

Обязательно тестируй:

1. Успешную загрузку.
2. Слишком большой файл.
3. Неподдерживаемый формат.
4. Ошибку загрузки в хранилище.
5. Воспроизведение.
6. Перемотку.
7. HTTP Range Requests.
8. Доступ к публичному видео.
9. Отказ в доступе к приватному видео.
10. Удаление или скрытие видео.

Не считай реализацию завершённой,
пока основной сценарий не проверен.
