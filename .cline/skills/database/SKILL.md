# Навык работы с базой данных

В проекте используется PostgreSQL,
SQLAlchemy 2.0 и Alembic.

Я хочу, чтобы работа с БД была понятной
и организованной.

## Модели

Используй современный синтаксис SQLAlchemy 2.0:

- DeclarativeBase.
- Mapped.
- mapped_column.
- relationship.

Для связанных данных правильно выбирай:
- selectinload.
- joinedload.
- lazy loading, если он действительно нужен.

Не допускай случайных дополнительных запросов.

## Асинхронность

Используй AsyncSession.

Все асинхронные операции должны иметь await.

Не создавай отдельные подключения к БД
внутри сервисов.

Используй сессию, переданную через зависимости.

## Запросы

Для SELECT используй select.

Для добавления записей используй add.

Для выполнения запросов используй execute.

Для получения одного значения используй scalar_one,
scalar_one_or_none или подходящий метод.

Для получения списка используй scalars().all().

Выбирай метод получения результата
в зависимости от ожидаемого результата запроса.

## Транзакции

Продумывай, где должны происходить commit
и rollback.

Не выполняй commit после каждой отдельной
операции, если они являются частью одной транзакции.

Не забывай обрабатывать ошибки транзакций.

## Репозитории

Все запросы к базе данных размещай
в репозиториях.

Сервисы должны использовать репозитории
для работы с данными.

Не размещай SQL-запросы в endpoint.

## Alembic

При изменении моделей проверяй,
нужна ли миграция.

Создавай миграции через Alembic.

Не редактируй базу вручную вместо миграций.

Перед применением миграции изучи,
какие изменения она выполняет.

Не удаляй существующие миграции.

## Проверка

После изменения БД:
1. Проверь миграцию.
2. Проверь связи таблиц.
3. Проверь ограничения.
4. Проверь индексы.
5. Проверь работу запросов.
6. Проверь связанные данные.

Не создавай лишние таблицы и связи.
Объясняй, зачем они нужны.
