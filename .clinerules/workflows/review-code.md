
# Проверка кода

<task_objective>
Проверь недавно написанный или изменённый код.

Твоя задача — найти проблемы,
а не переписать всё приложение.
</task_objective>

<detailed_sequence_of_steps>

1. Изучи изменённые файлы.

2. Изучи git diff.

3. Проверь соответствие архитектуре проекта.

4. Проверь:
   - правильность логики;
   - ошибки в асинхронном коде;
   - обработку исключений;
   - SQL-запросы;
   - работу транзакций;
   - типизацию;
   - возможное дублирование кода.

5. Проверь безопасность:
   - авторизацию;
   - проверку ролей;
   - доступ к чужим данным;
   - обработку файлов;
   - защиту секретов.

6. Проверь наличие тестов.

7. Если возможно, запусти существующие тесты
   через venv

8. Не изменяй код автоматически.

9. Подготовь список замечаний.

Для каждого замечания укажи:
- Файл.
- Строку или участок кода.
- В чём проблема.
- Почему это проблема.
- Как лучше исправить.

10. Раздели замечания на:
   - Критические.
   - Важные.
   - Незначительные.

</detailed_sequence_of_steps>

<important_notes>
Не придумывай ошибки.

Не предлагай переписывать работающий код
только ради другого стиля.

Если проблем не найдено, сообщи об этом,
но укажи, какие проверки действительно выполнены.
</important_notes>
