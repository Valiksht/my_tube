
# Аудит проекта

<task_objective>
Я хочу получить информацию о текущем состоянии
проекта перед началом новой разработки.

Не изменяй код. Проведи аудит.
</task_objective>

<detailed_sequence_of_steps>

1. Изучи структуру проекта.

2. Определи основные модули и их назначение.

3. Изучи основные файлы:
   - main.py
   - конфигурацию
   - подключение к БД
   - модели
   - схемы
   - API
   - сервисы
   - репозитории

4. Проверь зависимости и requirements.txt.

5. Проверь наличие виртуального окружения venv

6. Изучи существующие тесты.

7. Проверь текущую архитектуру и найди:
   - дублирование кода;
   - неправильное разделение ответственности;
   - лишние зависимости;
   - потенциальные проблемы безопасности;
   - незавершённые функции.

8. Если необходимо, запусти безопасные
   проверочные команды.

9. Не устанавливай пакеты и не изменяй файлы.

10. Подготовь отчёт:
    - Что уже реализовано.
    - Что работает.
    - Какие проблемы найдены.
    - Что нужно исправить.
    - Какие задачи приоритетнее.

</detailed_sequence_of_steps>

<important_notes>
Не делай выводы по одним только названиям файлов.
Изучай содержимое.

Не утверждай, что функция работает,
если не проверил её.

Не исправляй найденные проблемы самостоятельно.
</important_notes>
