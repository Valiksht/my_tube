КРИТИЧЕСКОЕ ПРАВИЛО ДЛЯ РАБОТЫ С ФАЙЛАМИ:
НИКОГДА не используй терминал (инструмент execute_command) для создания, чтения или изменения файлов.
НИКОГДА не используй команды echo, cat, Set-Content, Out-File или python -c для записи кода.
ВСЕГДА используй только свои встроенные инструменты (write_to_file, replace_in_file, read_file) для ЛЮБЫХ изменений в файлах. Попытка записать многострочный код через терминал сломает систему.
