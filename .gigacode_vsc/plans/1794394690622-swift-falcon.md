## 2. Проблемы с базой данных

### 2.1 Критическая проблема: `.env` не работает корректно

Файл `.env` содержит:
```
DATABASE_URL=postgresql+asyncpg://${POSTGRES_USER}:${POSTGRES_PASSWORD}@localhost:${POSTGRES_PORT}/${POSTGRES_DB}
```

**Проблема:** Python `os.getenv()` НЕ подставляет переменные `${...}`. Это синтаксис оболочки, а не Python.

**Решение:** Нужно либо:
- Использовать `pydantic-settings` для сборки URL из отдельных переменных
- Либо прописать `DATABASE_URL` напрямую в `.env`

### 2.2 Docker Compose

- ✅ PostgreSQL настроен с healthcheck
- ❌ MinIO отсутствует (нужен для хранения видео)
- ❌ Нет сервиса для фонового worker (FFmpeg обработка)

### 2.3 Миграции

- ✅ Базовая миграция создана
- ❌ Не применена (БД не запущена)
- ⚠️ `.gitignore` исключает `alembic/` — миграции не будут в репозитории

## 6. Риски и рекомендации

1. **Windows PowerShell** — некоторые команды Docker/MongoDB могут работать иначе
2. **FFmpeg** — нужно установить отдельно на Windows для обработки видео
3. **MinIO** — требует отдельного контейнера и настройки
4. **Асинхронность** — FFmpeg вызовы блокирующие, нужно использовать threadpool
