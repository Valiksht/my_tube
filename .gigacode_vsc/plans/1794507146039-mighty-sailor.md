# План исправления бага: видео не воспроизводится после загрузки

## ИТОГО: Проблема решена

### Корневая причина

**MinIO bucket `videos` не имел публьной политики доступа.**

Файл видео загружался в MinIO успешно, но бакет был создан `minio-init` контейнером без публьного доступа. Браузер получал URL `http://localhost:9000/videos/videos/11.mp4`, но при попытке загрузить файл получал `403 Access Denied`.

### Почему это произошло

1. `minio-init` создаёт бакет `videos` при старте Docker (без публьной политики)
2. В `app/storage/minio.py` код установки публичной политики был внутри условия:
   ```python
   if not self.client.bucket_exists(self.bucket):
       self.client.make_bucket(self.bucket)
       # политика устанавливалась ТОЛЬКО при создании бакета
   ```
3. Бакет уже существовал → условие ложно → политика не устанавливалась → файлы недоступны

### Исправления

#### 1. Код: `app/storage/minio.py` (строки 63-81)

**Было:**
```python
if not self.client.bucket_exists(self.bucket):
    self.client.make_bucket(self.bucket)
    policy = {...}
    self.client.set_bucket_policy(self.bucket, json.dumps(policy))
```

**Стало:**
```python
if not self.client.bucket_exists(self.bucket):
    self.client.make_bucket(self.bucket)

# Всегда применяем политику — бакет мог быть создан minio-init
policy = {...}
self.client.set_bucket_policy(self.bucket, json.dumps(policy))
```

Политика теперь устанавливается при КАЖДОЙ загрузке файла, независимо от существования бакета.

#### 2. Ручное применение политики к существующему бакету

```bash
docker exec mytube_minio mc alias set mylocal http://localhost:9000 minioadmin minioadmin
docker exec mytube_minio mc anonymous set public mylocal/videos
```

### Результат проверки

```
curl http://localhost:9000/videos/videos/11.mp4
HTTP Status: 200

```

Видео доступно для воспроизведения.

### Что нужно сделать пользователю

1. Открыть `http://localhost:8000/video/11` в браузере
2. Видео должно воспроизводиться

### Последующие загрузки

Все новые видео будут автоматически доступны, так как код теперь всегда устанавливает публьную политику бакета при загрузке файла.

### Дополнительные улучшения (опционально)

1. **Применять политику при инициализации приложения** — добавить в `lifespan()` вызов `set_bucket_policy`
2. **Исправить minio-init** — добавить установку политики в скрипт инициализации
3. **Добавить проверку доступности** — добавить метод `is_available()` для MinIOStorage
