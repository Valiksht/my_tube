# План переноса HTML-эндпоинтов из main.py в роутеры

## Текущее состояние

`app/main.py` содержит **12 HTML-эндпоинтов** + health-check + CSRF-мидлвар + CORS + статика.
`app/api/` уже содержит роутеры для JSON-API: `auth`, `videos`, `likes`, `subscriptions`, `channels`, `moderation`.

## Цели

1. Перенести все HTML-эндпоинты из `main.py` в отдельные роутеры внутри `app/api/`.
2. Убрать дублирование эндпоинта `POST /api/auth/logout` (дублируется в `main.py` и `app/api/auth.py`).
3. Подключить новые роутеры через `app/api/__init__.py`.
4. Оставить в `main.py` только: lifespan, middleware (CORS, CSRF), статика, templates, health-check, подключение роутеров.

## Структура файлов

Создаю **один новый файл** для всех HTML-страниц:

```
app/api/
├── __init__.py          — обновить: подключить pages_router
├── auth.py              — без изменений (JSON API)
├── videos.py            — без изменений (JSON API + комментарии)
├── likes.py             — без изменений
├── subscriptions.py     — без изменений
├── channels.py          — без изменений
├── moderation.py        — без изменений (JSON API)
└── pages.py             — НОВЫЙ: все HTML-эндпоинты
```

## Logout-эндпоинт

В `main.py` есть `POST /api/auth/logout` (строки 279–304), который **дублирует** эндпоинт в `app/api/auth.py`.

Решение: **перенести** его в `pages.py` как `POST /api/auth/logout`. JSON-версия в `auth.py` возвращает 204 (для API-клиентов), а HTML-версия в `pages.py` — редирект на `/` (для браузеров). Оба эндпоинта имеют одинаковый путь, но разные методы — они не конфликтуют.

## Итоговая структура `main.py` после переноса

```python
"""Главный файл приложения YouTube Clone."""

from contextlib import asynccontextmanager

from fastapi import FastAPI, Request
from fastapi.middleware.cors import CORSMiddleware
from fastapi.staticfiles import StaticFiles
from fastapi.templating import Jinja2Templates

from app.core.config import get_settings
from app.api.__init__ import router as api_router

settings = get_settings()


@asynccontextmanager
async def lifespan(app: FastAPI):
    yield


app = FastAPI(...)
app.add_middleware(CORSMiddleware, ...)
app.mount("/static", StaticFiles(...), ...)
templates = Jinja2Templates(...)


@app.middleware("http")
async def add_csrf_token(request: Request, call_next):
    ...


@app.get("/health")
def health_check():
    return {"status": "ok", "app": settings.app_name}


app.include_router(api_router, prefix="/api")
```
