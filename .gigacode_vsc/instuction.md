## Правила работы с инструментами записи файлов

1. Перед вызовом Write всегда формируй оба обязательных аргумента:
   `filePath` (путь к файлу) и `content` (полное содержимое файла).
   Никогда не вызывай Write с пустыми или отсутствующими аргументами.

2. Если не уверен в точном содержимом файла — сначала прочитай файл
   инструментом Read, только потом записывай. Не генерируй содержимое
   по памяти из предыдущего контекста.

3. Если вызов Write был отклонён из-за неверной схемы аргументов —
   не повторяй тот же вызов. Сформируй его заново с нуля, явно
   перечислив filePath и content.

4. При записи больших файлов (>200 строк) сначала выведи план правок
   текстом, а затем пиши файл одним вызовом — не дроби на десятки
   мелких вызовов.

5. Контекст держи минимальным: не читай файлы, которые не нужны
   для текущего шага задачи.
