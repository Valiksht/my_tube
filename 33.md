## Discoveries

1. **MinIO on Windows Docker Desktop is broken** — Bitnami MinIO image fails with "access denied" errors on volume mounts. Switched local docker-compose to use filesystem storage instead.

2. **Cascading import errors** — Multiple files had issues:
   - `app/services/__init__.py` imported `auth_service` and `video_service` which were removed (global singletons with `None`)
   - `app/api/auth.py` was missing `get_db` import — fixed by adding `from app.database.dependencies import get_db`
   - `app/main.py` had `@app.middleware("http")` decorator placed BEFORE `app` was defined — moved it after the app definition

3. **Alembic migrations need manual run** — The Docker container doesn't auto-run migrations on startup in the local setup. Ran `docker exec mytube_api_local alembic upgrade head` manually.

4. **Jinja2 template cache error** — Current blocking error: `TypeError: unhashable type: 'dict'` in Jinja2 cache. This happens in `TemplateResponse` when passing a dict as the `context` parameter. The issue is in `app/main.py` line 103 where `templates.TemplateResponse` is called — Jinja2's `TemplateResponse` expects the context to be passed differently than Django's.

5. **Current state**: API container is running, health endpoint works (`/health` returns 200), Swagger docs work (`/docs` returns 200), but the main page (`/`) returns 500 Internal Server Error due to the Jinja2 template issue.
